# 🌦️ Weather Aggregator

A modern full-stack Weather Aggregator web application that provides current weather conditions, hourly forecasts, daily forecasts, and detailed weather metrics for searched locations.

## 🚀 Features

- 🔍 Search weather by city/location
- 🌡️ Current weather information
- ⏱️ Hourly weather forecast
- 📅 Daily weather forecast
- 💨 Detailed weather metrics
- 🌍 Location-based weather data
- 📱 Responsive modern UI
- ⚡ Fast React frontend
- 🐍 FastAPI backend
- 🔗 Frontend and backend API integration

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Python
- FastAPI
- HTTPX

### Weather Data
- Open-Meteo API
